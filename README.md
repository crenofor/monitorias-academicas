# Sistema de Monitorias Acadêmicas

## 1. Descrição do Projeto

O Sistema de Monitorias Acadêmicas é uma aplicação web desenvolvida para facilitar o encontro entre alunos que precisam de auxílio em determinadas disciplinas e monitores disponíveis.

A aplicação busca centralizar informações sobre disciplinas, monitores, horários e solicitações de atendimento, tornando o processo de busca por monitorias mais simples e organizado.

## 2. Objetivos

- Facilitar a busca por monitores e disciplinas.
- Permitir a consulta de horários disponíveis.
- Permitir solicitações de monitoria.
- Acompanhar o status das solicitações.
- Demonstrar comunicação reativa entre clientes.
- Aplicar princípios básicos de acessibilidade web.

## 3. Público-alvo

- Alunos.
- Monitores.
- Professores.
- Coordenadores.

## 4. Eixo Tecnológico

**Eixo 1 — Tempo Real**

A prova de conceito utiliza a API `BroadcastChannel` para demonstrar a comunicação reativa entre abas da aplicação, permitindo a transmissão de eventos sem recarregamento da página.

Clone o repositório:

Execute em ambiente de desenvolvimento:

npm run dev

Acesse o endereço local informado pelo servidor no terminal.
